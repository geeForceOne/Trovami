# Release notes

## 1.2.0 - 2026-11-04

### New

- Select several items on a location's or keyword's page to move or delete them together.
- The item page has buttons to go to the previous or next item at the same location.

### Improved

- After adding a location you stay where you are, with the new location visible in the tree.
- The New location form starts with the kind you used last.
- Inventory opens the location you last picked.

### Fixed

- Bitwarden no longer fills the mail server, backup and AI key passwords.

## 1.1.0 - 2026-11-04

### New

- Typing a keyword now suggests the ones you already use, so you can reuse them.
- Keywords can have a color, which shows wherever they appear.
- Pin a keyword to keep it in the menu below the Inbox, even with no items.
- Every item you add gets the keyword "new", so you can go through what came in. It comes off by hand, or after 30 days; each household's owner can change or turn off the days.
- When the AI isn't sure what an item is, it adds the keyword "unsure", so you can find and check those items.
- The phone app's location lists have a refresh button.
- A keyword's page shows all the keywords of its items, and you can remove any of them right there.

### Improved

- New location and Edit location are now the same form, with notes, keywords and a photo in both.
- Pages use the full window width, and the location tree is wider.
- Household settings and QR labels moved into the household menu.
- Keywords save as soon as you press comma or Enter, or remove one, without pressing Save.
- The item page has a Close button that takes you back to where you came from.
- On phones, Cancel and Save stay in sight in long dialogs.

### Fixed

- Bitwarden no longer tries to fill fields that aren't logins, like AI keys and invite addresses.

## 1.0.1 - 2026-11-02

### New

- You can connect a phone by typing the code from Profile, as well as by scanning it.

### Improved

- When the phone app can't connect, the message now says why.

### Fixed

- The phone app can connect to a server on your local network on Android 17.
- Scanning a pairing code now shows the scanned server address on the sign-in form.
- Behind a reverse proxy, redirects stay on https.
