# Release notes

## 1.0.1 - 2026-11-02

### New

- You can connect a phone by typing the code from Profile, as well as by scanning it.

### Improved

- When the phone app can't connect, the message now says why.

### Fixed

- The phone app can connect to a server on your local network on Android 17.
- Scanning a pairing code now shows the scanned server address on the sign-in form.
- Behind a reverse proxy, redirects stay on https.
